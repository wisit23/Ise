# Customer Journey Map — Buyer

**Persona:** มิ้น (Mint) — ผู้ซื้อเสื้อผ้ามือสอง
**Role:** Buyer
**Scenario:** มิ้นต้องการซื้อเสื้อผ้ามือสองที่ตรงกับสไตล์และงบของตัวเอง แต่การค้นหาผ่าน Marketplace ทั่วไปใช้เวลานานและยากต่อการตรวจสอบความน่าเชื่อถือของสินค้าและผู้ขาย เธอจึงต้องการแพลตฟอร์มที่ช่วยค้นหาของตรงใจได้เร็ว ตรวจสอบข้อมูลก่อนซื้อได้ครบ และซื้อขายได้อย่างมั่นใจ

---

## 1. Persona Summary

| หัวข้อ | รายละเอียด |
| --- | --- |
| **Need & Goals** | หาเสื้อผ้ามือสองที่ตรงสไตล์ ไซส์ และงบประมาณ / ค้นหาได้รวดเร็วไม่เสียเวลาไถหา / มั่นใจว่าสินค้าและผู้ขายน่าเชื่อถือ / ซื้อได้อย่างปลอดภัยและติดตามสถานะได้ |
| **Behavior** | ค้นหาผ่าน Marketplace และ Social Media / ใช้ Filter เลือกแบรนด์ ราคา ไซส์ สภาพสินค้า / ดูรูปสินค้า รีวิว และประวัติผู้ขายก่อนซื้อ / แชทถามรายละเอียดเมื่อไม่มั่นใจ / บันทึกสินค้าที่สนใจไว้ก่อนตัดสินใจ |
| **Frustration** | เสียเวลาไถหานานแต่ของไม่ตรงความต้องการ / Filter ไม่ละเอียดพอ / กลัวของไม่ตรงปก มีตำหนิ หรือโดนโกง / ข้อมูลและรูปสินค้าไม่ครบ / กลัวสินค้าที่ชอบถูกคนอื่นซื้อไปก่อน |

---

## 2. Journey Map Overview

| # | Stage | Emotion Curve |
| --- | --- | --- |
| 1 | Awareness — รู้จักแพลตฟอร์ม | Neutral → Curious (3/5) |
| 2 | Onboarding — สมัครและตั้งค่าสไตล์ | Hopeful (4/5) |
| 3 | Discovery — ค้นหา / Swipe หาสินค้า | Excited (5/5) |
| 4 | Evaluation — ตรวจสอบสินค้าและผู้ขาย | Cautious (2/5) |
| 5 | Consideration — บันทึกไว้ / สอบถามผู้ขาย | Hesitant (2/5) |
| 6 | Purchase — สั่งซื้อและชำระเงิน | Nervous → Relieved (3/5) |
| 7 | Fulfillment — ติดตามสถานะและรับสินค้า | Anxious → Satisfied (4/5) |
| 8 | Post-Purchase — รีวิวและกลับมาซื้อซ้ำ | Confident / Loyal (5/5) |

## 3. Journey Map (Detail)

### Stage 1 — Awareness / รับรู้แพลตฟอร์ม

| หัวข้อ | รายละเอียด |
| --- | --- |
| **User Goal** | อยากหาช่องทางซื้อเสื้อผ้ามือสองที่ดีกว่า Marketplace เดิมที่ใช้อยู่ |
| **Action** | เห็นโฆษณา / โพสต์รีวิวจากเพื่อนบน Social Media แล้วกดเข้ามาดูหน้าแรกของเว็บ เลื่อนดูสินค้าแนะนำและอ่านว่าแพลตฟอร์มนี้ต่างจากที่อื่นอย่างไร |
| **Touchpoint** | Social Media Ad / Post, Landing Page (`/`), Featured Products, Footer (About & นโยบายความปลอดภัย) |
| **Thinking** | "เว็บนี้คืออะไร มีของที่เราชอบไหม" / "จะต่างจาก Marketplace เดิมยังไง" / "จะปลอดภัยกว่าจริงหรือเปล่า" |
| **Feeling** | สนใจแต่ยังไม่เชื่อใจ — Curious (3/5) |
| **Pain Point** | ยังไม่รู้จักแบรนด์ ไม่มั่นใจว่าจะปลอดภัยกว่าเดิม / หน้าแรกยังไม่สื่อสารจุดต่างชัดพอ / ต้องสมัครสมาชิกก่อนถึงจะเห็นของ ทำให้เสียความสนใจ |
| **Opportunity** | ทำ Value Proposition บนหน้าแรกให้ชัด ("ระบบตรวจสอบผู้ขาย + คุ้มครองการชำระเงิน") / เปิดให้ Browse และลอง Swipe ได้ก่อนสมัคร (Guest Mode) / โชว์ Social Proof เช่น จำนวนดีลสำเร็จและคะแนนรีวิวเฉลี่ยบนหน้าแรก |

### Stage 2 — Onboarding / สมัครสมาชิกและตั้งค่าสไตล์

| หัวข้อ | รายละเอียด |
| --- | --- |
| **User Goal** | เริ่มใช้งานให้เร็วที่สุด และบอกระบบว่าตัวเองชอบสไตล์ไหน ไซส์อะไร งบเท่าไร |
| **Action** | สมัครสมาชิก ยืนยันอีเมล กรอกโปรไฟล์ เลือกสไตล์ที่ชอบ (Vintage / Streetwear / Minimal), ระบุไซส์ (S/M/L) และช่วงราคาที่รับได้ |
| **Touchpoint** | หน้า Register (`/register`), หน้า Login (`/login`), Email Verification, หน้า Profile / Style Preference (`/profile`) |
| **Thinking** | "ขอสมัครเร็วๆ ไม่อยากกรอกเยอะ" / "ถ้าบอกสไตล์กับไซส์ไป ระบบจะหาของให้ตรงใจขึ้นจริงไหม" / "ข้อมูลส่วนตัวของเราปลอดภัยไหม" |
| **Feeling** | คาดหวัง แต่กลัวขั้นตอนเยอะ — Hopeful (4/5) |
| **Pain Point** | ฟอร์มสมัครยาว ต้องกรอกหลายขั้น / ยังไม่เข้าใจว่าตั้งค่าสไตล์ไปแล้วได้ประโยชน์อะไร / ถ้าข้ามขั้นตอนตั้งค่า ระบบจะแนะนำของมั่วไม่ตรงใจ |
| **Opportunity** | สมัครด้วย Social Login เพื่อลดขั้นตอน / ทำ Onboarding แบบ Swipe เลือกรูปสไตล์ที่ชอบ 5-10 ใบ แทนการกรอกฟอร์ม / บันทึกไซส์และงบเป็น Default Filter อัตโนมัติทุกครั้งที่ค้นหา / อธิบายผลลัพธ์ทันที ("เราจะแนะนำของที่ตรงไซส์ M และไม่เกิน 800 บาทให้คุณ") |

### Stage 3 — Discovery / ค้นหาและ Swipe สินค้า

| หัวข้อ | รายละเอียด |
| --- | --- |
| **User Goal** | เจอเสื้อผ้าที่ตรงสไตล์ ไซส์ และงบ ได้เร็วที่สุด โดยไม่ต้องไถหาเป็นชั่วโมง |
| **Action** | ใช้ช่องค้นหาและ Filter (แบรนด์ / หมวดหมู่ / ไซส์ / ช่วงราคา / สภาพสินค้า / สี) จากนั้นเข้าโหมด Swipe ปัดขวาเพื่อเก็บของที่ชอบ ปัดซ้ายเพื่อข้าม และเลื่อนดูรายการสินค้าแบบ Grid |
| **Touchpoint** | หน้า Products (`/products`), Filter & Sort Panel, Search Bar, หน้า Swipe (`/swipe`), Product Card, Pagination |
| **Thinking** | "ปัดสนุกดี เจอของถูกใจเร็วกว่าไถ Marketplace" / "ทำไมยังมีของไซส์ที่เราใส่ไม่ได้โผล่มาอีก" / "อยากกรองเฉพาะสภาพเหมือนใหม่เท่านั้น" |
| **Feeling** | สนุกและตื่นเต้น — Excited (5/5) แต่เริ่มหงุดหงิดถ้าผลลัพธ์ไม่ตรง |
| **Pain Point** | ผลการค้นหายังมีของที่ไม่ตรงไซส์หรือเกินงบปนมา / Filter ยังไม่ละเอียดพอ (ไม่มีกรองสภาพสินค้าและตำหนิ) / ปัดไปเยอะแล้วของหมด ไม่มีของใหม่มาเติม / ปัดผ่านของที่ชอบไปแล้วย้อนกลับไม่ได้ |
| **Opportunity** | Filter ละเอียดระดับสภาพสินค้า (ใหม่ / เหมือนใหม่ / สภาพดี / มีตำหนิเล็กน้อย) พร้อมกรองตามการวัดจริง (อก/เอว/ความยาว) / จำ Filter ล่าสุดไว้ให้อัตโนมัติ / ปุ่ม Undo ย้อนการ Swipe ครั้งล่าสุด / Recommendation Engine เรียนรู้จากประวัติการปัด / บันทึกเงื่อนไขค้นหาเป็น Saved Search แล้วแจ้งเตือนเมื่อมีของใหม่ตรงเงื่อนไข |

### Stage 4 — Evaluation / ตรวจสอบสินค้าและผู้ขาย

| หัวข้อ | รายละเอียด |
| --- | --- |
| **User Goal** | มั่นใจว่าสินค้าตรงปก ไม่มีตำหนิที่รับไม่ได้ และผู้ขายเชื่อถือได้ |
| **Action** | เปิดหน้ารายละเอียดสินค้า ซูมดูรูปทุกมุมและวิดีโอ อ่านสภาพสินค้าและขนาดที่วัดจริง กดเข้าโปรไฟล์ผู้ขายเพื่อดูคะแนนรีวิว จำนวนการขายสำเร็จ และอ่านรีวิวจากผู้ซื้อคนก่อน |
| **Touchpoint** | หน้า Product Detail (`/products/[id]`), Media Gallery (รูป + วิดีโอ), Condition & Size Spec, หน้า Seller Store (`/store/[id]`), Star Rating, Review List, Verified Seller Badge |
| **Thinking** | "รูปสวยแต่ของจริงจะเหมือนไหม" / "ตำหนิตรงคอเสื้อรับได้หรือเปล่า" / "ผู้ขายคนนี้ขายมากี่ชิ้นแล้ว มีรีวิวไม่ดีไหม" / "ถ้าของมาไม่ตรงปก จะเคลมได้ไหม" |
| **Feeling** | ระแวงและลังเลที่สุดในทั้ง Journey — Cautious (2/5) |
| **Pain Point** | รูปน้อย ไม่มีรูปตำหนิชัดๆ / ไม่บอกขนาดที่วัดจริง ทำให้เดาไซส์ไม่ได้ / ผู้ขายใหม่ยังไม่มีรีวิว ตัดสินใจยาก / ไม่รู้ว่ามีการรับประกันหรือคืนสินค้าได้ไหม |
| **Opportunity** | บังคับผู้ขายอัปโหลดรูปขั้นต่ำ 4 มุม + รูปตำหนิ (Close-up) และกรอกขนาดวัดจริง ก่อนลงขายได้ / Verified Seller Badge จากการยืนยันตัวตน / สรุปคะแนนผู้ขายเป็นตัวเลขเดียวพร้อมสถิติ (อัตราส่งตรงเวลา / อัตราตรงปก) / แสดงนโยบายคืนสินค้าและการคุ้มครองการชำระเงินไว้ในหน้าสินค้า / AI ตรวจจับรูปซ้ำหรือรูปที่ก็อปมาจากเว็บอื่น |

---

### Stage 5 — Consideration / บันทึกไว้และสอบถามผู้ขาย

| หัวข้อ | รายละเอียด |
| --- | --- |
| **User Goal** | เคลียร์ข้อสงสัยที่เหลือ และเก็บของที่ชอบไว้เปรียบเทียบก่อนตัดสินใจ |
| **Action** | กด Favorite / เพิ่มลงตะกร้าไว้ก่อน แชทถามผู้ขายเรื่องตำหนิ ขนาดจริง และค่าส่ง เปรียบเทียบสินค้าที่บันทึกไว้หลายชิ้น รอผู้ขายตอบกลับ |
| **Touchpoint** | ปุ่ม Favorite / Wishlist, หน้า Cart (`/cart`), Chat กับผู้ขาย, Notification |
| **Thinking** | "รอผู้ขายตอบก่อนค่อยตัดสินใจ" / "ถ้าคิดนานเกินไป เดี๋ยวคนอื่นซื้อตัดหน้า" / "ชิ้นไหนคุ้มกว่ากันระหว่างสองตัวนี้" |
| **Feeling** | ลังเลและกดดันเรื่องเวลา — Hesitant (2/5) |
| **Pain Point** | ผู้ขายตอบช้าหรือไม่ตอบเลย ทำให้ตัดสินใจไม่ได้ / กลัวสินค้าถูกคนอื่นซื้อไปก่อนระหว่างรอคำตอบ (ปัญหาหลักของมิ้น) / ของในตะกร้าหายไปโดยไม่มีการแจ้งเตือน / เปรียบเทียบสินค้าหลายชิ้นพร้อมกันไม่ได้ |
| **Opportunity** | แสดงเวลาตอบกลับเฉลี่ยของผู้ขายและสถานะออนไลน์ / Quick Question แบบเลือกคำถามสำเร็จรูป (ตำหนิ / ขนาดจริง / ค่าส่ง) เพื่อให้ผู้ขายกดตอบได้ทันที / จองสินค้าชั่วคราว (Hold 15-30 นาที) ระหว่างตัดสินใจ / แจ้งเตือนเมื่อสินค้าที่บันทึกไว้เหลือชิ้นสุดท้าย ลดราคา หรือถูกขายไปแล้ว / หน้าเปรียบเทียบสินค้าแบบ Side-by-side |

### Stage 6 — Purchase / สั่งซื้อและชำระเงิน

| หัวข้อ | รายละเอียด |
| --- | --- |
| **User Goal** | จ่ายเงินให้เสร็จอย่างปลอดภัย โดยไม่ต้องกลัวว่าจะโดนโกง |
| **Action** | ตรวจสอบรายการในตะกร้า กรอกที่อยู่จัดส่ง เลือกวิธีจัดส่งและวิธีชำระเงิน ตรวจยอดรวมพร้อมค่าส่ง แล้วกดยืนยันคำสั่งซื้อ |
| **Touchpoint** | หน้า Cart (`/cart`), Checkout & Address Form, Shipping Option, Payment Gateway, Order Confirmation, Email / In-app Notification |
| **Thinking** | "โอนไปแล้วถ้าไม่ส่งของจะทำยังไง" / "ค่าส่งทำไมเพิ่งมาโผล่ตอนจ่าย" / "เงินจะถูกกันไว้จนกว่าจะได้รับของจริงไหม" |
| **Feeling** | กังวลตอนกดจ่าย แล้วโล่งเมื่อได้ใบยืนยัน — Nervous → Relieved (3/5) |
| **Pain Point** | ไม่มั่นใจว่าเงินจะปลอดภัยถ้าผู้ขายไม่ส่งของ / ค่าส่งไม่แสดงตั้งแต่ต้น ทำให้ยอดรวมเกินงบ / ขั้นตอน Checkout หลายหน้าเกินไป / ตัวเลือกการชำระเงินน้อย |
| **Opportunity** | ระบบ Escrow พักเงินไว้จนผู้ซื้อกดยืนยันรับของ พร้อมสื่อสารให้เห็นชัดตอน Checkout / แสดงค่าส่งประมาณการตั้งแต่หน้ารายละเอียดสินค้า / Checkout หน้าเดียวพร้อมจำที่อยู่เดิม / รองรับหลายช่องทาง (พร้อมเพย์ / บัตร / e-Wallet) / แสดง Trust Badge และนโยบายคุ้มครองผู้ซื้อบนหน้าจ่ายเงิน |

---

### Stage 7 — Fulfillment / ติดตามสถานะและรับสินค้า

| หัวข้อ | รายละเอียด |
| --- | --- |
| **User Goal** | รู้สถานะพัสดุตลอดเวลา และได้รับสินค้าตรงตามที่สั่ง |
| **Action** | เข้าดูสถานะคำสั่งซื้อ ติดตามเลขพัสดุ รอรับของ เปิดกล่องตรวจสอบสภาพจริงเทียบกับรูปในประกาศ แล้วกดยืนยันรับสินค้า |
| **Touchpoint** | หน้า Orders (`/orders`), Order Status Timeline, Tracking Number, Notification (อัปเดตสถานะ), ปุ่มยืนยันรับสินค้า / แจ้งปัญหา |
| **Thinking** | "ผู้ขายส่งของหรือยัง" / "ของจะถึงเมื่อไหร่" / "ถ้าของมาไม่ตรงปกต้องทำยังไงต่อ" |
| **Feeling** | ใจจดใจจ่อระหว่างรอ แล้วพอใจเมื่อของตรงปก — Anxious → Satisfied (4/5) |
| **Pain Point** | สถานะไม่อัปเดตแบบ Real-time ต้องเข้ามาเช็คเอง / ผู้ขายส่งช้าโดยไม่แจ้ง / ไม่รู้ขั้นตอนเมื่อของมีปัญหา ต้องติดต่อใคร / ถ้าไม่กดยืนยันรับของ ไม่รู้ว่าจะเกิดอะไรขึ้น |
| **Opportunity** | Timeline สถานะแบบ Real-time (ชำระเงิน → ผู้ขายยืนยัน → จัดส่ง → ถึงปลายทาง → สำเร็จ) พร้อม Push Notification ทุกครั้งที่เปลี่ยนสถานะ / เชื่อม API ขนส่งเพื่อดึงสถานะพัสดุอัตโนมัติ / ปุ่มแจ้งปัญหา / เปิดเคสคืนเงินภายในหน้าคำสั่งซื้อโดยตรง / กำหนดเวลาให้ผู้ขายต้องส่งของ และยกเลิกอัตโนมัติพร้อมคืนเงินหากเกินกำหนด |
