# As-Is User Journey Map — Buyer (ก่อนมีระบบ)

**Persona:** มิ้น (Mint) — ผู้ซื้อเสื้อผ้ามือสอง
**Role:** Buyer
**Context:** สถานการณ์ปัจจุบัน — มิ้นซื้อเสื้อผ้ามือสองผ่านช่องทางที่มีอยู่ (Facebook Marketplace, กลุ่มขายของมือสอง, Instagram, Twitter/X, Shopee) ยังไม่มีแพลตฟอร์มเฉพาะทาง
**Scenario:** มิ้นต้องการซื้อเสื้อผ้ามือสองที่ตรงกับสไตล์และงบของตัวเอง แต่การค้นหาผ่าน Marketplace ทั่วไปใช้เวลานานและยากต่อการตรวจสอบความน่าเชื่อถือของสินค้าและผู้ขาย

---

## 1. Persona Summary

| หัวข้อ           | รายละเอียด                                                                                                                                                                                              |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Need & Goals** | หาเสื้อผ้ามือสองที่ตรงสไตล์ ไซส์ และงบประมาณ / ค้นหาได้รวดเร็วไม่เสียเวลาไถหา / มั่นใจว่าสินค้าและผู้ขายน่าเชื่อถือ / ซื้อได้อย่างปลอดภัยและติดตามสถานะได้                                              |
| **Behavior**     | ค้นหาผ่าน Marketplace และ Social Media / ใช้ Filter เลือกแบรนด์ ราคา ไซส์ สภาพสินค้า / ดูรูปสินค้า รีวิว และประวัติผู้ขายก่อนซื้อ / แชทถามรายละเอียดเมื่อไม่มั่นใจ / บันทึกสินค้าที่สนใจไว้ก่อนตัดสินใจ |
| **Frustration**  | เสียเวลาไถหานานแต่ของไม่ตรงความต้องการ / Filter ไม่ละเอียดพอ / กลัวของไม่ตรงปก มีตำหนิ หรือโดนโกง / ข้อมูลและรูปสินค้าไม่ครบ / กลัวสินค้าที่ชอบถูกคนอื่นซื้อไปก่อน                                      |

---

## 2. Journey Overview (As-Is)

| #   | Stage                                    | Feeling                    | ระดับความรู้สึก |
| --- | ---------------------------------------- | -------------------------- | --------------- |
| 1   | Trigger — เกิดความต้องการอยากได้เสื้อผ้า | Motivated / ตั้งใจ         | 4/5             |
| 2   | Search — เริ่มค้นหาตามช่องทางต่างๆ       | Hopeful → Tired            | 3/5             |
| 3   | Browse — ไถหาสินค้าและกรองด้วยตัวเอง     | Frustrated / เหนื่อยล้า    | 1/5             |
| 4   | Evaluate — ตรวจสอบสินค้าและผู้ขาย        | Doubtful / ระแวง           | 2/5             |
| 5   | Contact — ทักแชทถามรายละเอียดและต่อราคา  | Impatient / รอนาน          | 2/5             |
| 6   | Payment — โอนเงินให้ผู้ขายโดยตรง         | Anxious / เสี่ยงที่สุด     | 1/5             |
| 7   | Waiting — รอของโดยไม่รู้สถานะ            | Worried / ลุ้น             | 2/5             |
| 8   | Receive — ได้รับของและจัดการปัญหาเอง     | Disappointed หรือ Relieved | 2/5             |

**Emotion Curve:** 4 → 3 → 1 → 2 → 2 → 1 → 2 → 2 (ต่ำตลอดทั้ง Journey ไม่มีจุดที่รู้สึกดีจริงๆ หลังจากเริ่มค้นหา)

## 3. As-Is Journey Map (Detail)

### Stage 1 — Trigger / เกิดความต้องการ

| หัวข้อ          | รายละเอียด                                                                                                                         |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| **User Goal**   | อยากได้เสื้อผ้าแนวที่ชอบเพิ่ม ในราคาที่ไม่แพงและไม่ซ้ำใคร                                                                          |
| **Action**      | เห็นลุคที่ชอบจาก Instagram / Pinterest / TikTok แล้วอยากได้แบบนั้น จึงตั้งงบในใจ (เช่น ไม่เกิน 800 บาท) และนึกถึงช่องทางที่เคยซื้อ |
| **Touchpoint**  | Instagram, TikTok, Pinterest, รูปแฟชั่นจากเพื่อน, แกลเลอรีรูปในเครื่อง                                                             |
| **Thinking**    | "อยากได้เสื้อแนวนี้ แต่ของใหม่แพงเกินงบ" / "ซื้อมือสองน่าจะได้ของแปลกและถูกกว่า" / "ไม่รู้จะเริ่มหาจากตรงไหนดี"                    |
| **Feeling**     | ตั้งใจและมีแรงจูงใจ — Motivated (4/5)                                                                                              |
| **Pain Point**  | ไม่มีที่รวมของมือสองแนวที่ชอบโดยเฉพาะ ต้องเริ่มจากศูนย์ทุกครั้ง / รู้แค่ว่าอยากได้ "แนวนี้" แต่บอกเป็นคำค้นหาไม่ถูก                |
| **Opportunity** | มีแพลตฟอร์มเฉพาะทางสำหรับเสื้อผ้ามือสองที่จัดหมวดตามสไตล์ / ค้นหาจากรูปที่ชอบ (Image Search) แทนการพิมพ์คำค้น                      |

---

### Stage 2 — Search / เริ่มค้นหา

| หัวข้อ          | รายละเอียด                                                                                                                                                              |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **User Goal**   | หาแหล่งที่มีของแนวที่ต้องการ ในงบที่ตั้งไว้                                                                                                                             |
| **Action**      | เปิดหลายแอปสลับไปมา — พิมพ์คำค้นใน Facebook Marketplace, เข้ากลุ่มขายของมือสองหลายกลุ่ม, ค้นแฮชแท็กใน Instagram และ Twitter/X, ลองเสิร์ชใน Shopee                       |
| **Touchpoint**  | Facebook Marketplace, Facebook Groups (กลุ่มมือสอง), Instagram Hashtag & Explore, Twitter/X, Shopee, LINE OpenChat                                                      |
| **Thinking**    | "ต้องเปิดกี่แอปถึงจะเจอ" / "แต่ละที่คำค้นไม่เหมือนกัน ต้องพิมพ์ใหม่ทุกที่" / "โพสต์เก่าตั้งแต่ปีที่แล้วยังโผล่มาอยู่เลย"                                                |
| **Feeling**     | ยังมีความหวังแต่เริ่มเหนื่อย — Hopeful → Tired (3/5)                                                                                                                    |
| **Pain Point**  | ข้อมูลกระจัดกระจายหลายแพลตฟอร์ม ไม่มีที่เดียวที่ครบ / ต้องพิมพ์คำค้นซ้ำในทุกช่องทาง / ผลลัพธ์ปนกับของใหม่และของไม่เกี่ยวข้อง / โพสต์เก่าที่ขายไปแล้วยังอยู่ในผลการค้นหา |
| **Opportunity** | รวมสินค้ามือสองไว้ในที่เดียว แยกหมวดหมู่ชัดเจน / ระบบจัดการสถานะสินค้าอัตโนมัติ (ขายแล้วหายจากผลค้นหาทันที) / บันทึกเงื่อนไขค้นหาไว้ใช้ซ้ำได้                           |

---

### Stage 3 — Browse / ไถหาสินค้าและกรองเอง

| หัวข้อ          | รายละเอียด                                                                                                                                                                                                                                                                       |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **User Goal**   | คัดกรองให้เหลือเฉพาะของที่ตรงสไตล์ ไซส์ และงบ                                                                                                                                                                                                                                    |
| **Action**      | เลื่อนฟีดดูโพสต์ทีละอัน อ่านแคปชันเพื่อหาไซส์และราคา (เพราะไม่มีช่องข้อมูลแยก) ใช้ Filter เท่าที่แพลตฟอร์มมี (ราคา + ระยะทาง) แล้วต้องมากรองไซส์และสภาพสินค้าด้วยตาเอง เซฟรูปหรือแคปหน้าจอเก็บไว้                                                                                |
| **Touchpoint**  | Feed ของ Marketplace, Filter พื้นฐาน (ราคา/ระยะทาง/หมวดหมู่กว้างๆ), แคปชันโพสต์, ปุ่ม Save Post, แกลเลอรีรูปในเครื่อง (แคปหน้าจอ)                                                                                                                                                |
| **Thinking**    | "ไถมาครึ่งชั่วโมงแล้ว ยังไม่เจอที่ถูกใจเลย" / "ตัวนี้สวยแต่ไม่บอกไซส์ ต้องทักถามอีก" / "ทำไมกรองไซส์ไม่ได้" / "เมื่อกี้เลื่อนผ่านตัวที่ชอบไป หาไม่เจอแล้ว"                                                                                                                       |
| **Feeling**     | หงุดหงิดและเหนื่อยล้าที่สุด — Frustrated (1/5)                                                                                                                                                                                                                                   |
| **Pain Point**  | **เสียเวลาไถหานานมากแต่ของที่เจอไม่ตรงความต้องการ** / **Filter ไม่ละเอียดพอ — กรองไซส์ แบรนด์ สภาพสินค้าไม่ได้** / ผู้ขายเขียนแคปชันไม่เป็นมาตรฐาน บางโพสต์ไม่บอกไซส์หรือราคา / ไม่มีที่เก็บของที่สนใจอย่างเป็นระบบ ต้องแคปหน้าจอเอง / เลื่อนผ่านของที่ชอบไปแล้วย้อนกลับหาไม่เจอ |
| **Opportunity** | Filter ละเอียดถึงระดับไซส์ แบรนด์ สภาพสินค้า และสี / บังคับกรอกข้อมูลมาตรฐานตอนลงขาย (ไซส์/ราคา/สภาพ) / ระบบแนะนำสินค้าตามสไตล์ที่เคยสนใจ เพื่อลดเวลาไถ / Wishlist ในระบบแทนการแคปหน้าจอ                                                                                         |

---

### Stage 4 — Evaluate / ตรวจสอบสินค้าและผู้ขาย

| หัวข้อ          | รายละเอียด                                                                                                                                                                                                                                                                                         |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **User Goal**   | มั่นใจว่าของตรงปก ไม่มีตำหนิที่รับไม่ได้ และคนขายไม่ใช่มิจฉาชีพ                                                                                                                                                                                                                                    |
| **Action**      | ซูมดูรูปทีละใบ (ซึ่งมักมีแค่ 1-2 รูปและถ่ายไม่ชัด) ไปส่องโปรไฟล์ Facebook ของผู้ขายว่าเป็นบัญชีจริงไหม ดูวันที่สร้างบัญชีและจำนวนเพื่อน เอาชื่อและเลขบัญชีไปเสิร์ชในกลุ่มแฉโกง ถามเพื่อนว่าเคยซื้อจากร้านนี้ไหม                                                                                    |
| **Touchpoint**  | รูปในโพสต์, โปรไฟล์ Facebook/Instagram ของผู้ขาย, กลุ่ม "แฉคนโกง" / เว็บเช็คเลขบัญชีมิจฉาชีพ, รีวิวที่ผู้ขายแคปมาลงเอง, แชทถามเพื่อน                                                                                                                                                               |
| **Thinking**    | "รูปสวยแต่ของจริงจะเหมือนไหม" / "รีวิวที่เขาแคปมาลงเอง จะจริงหรือทำขึ้นมาเอง" / "บัญชีนี้เพิ่งสร้างเมื่อเดือนที่แล้ว น่าสงสัย" / "ถ้าโดนโกงจะทำอะไรได้บ้าง"                                                                                                                                        |
| **Feeling**     | ระแวงและไม่ไว้ใจ — Doubtful (2/5)                                                                                                                                                                                                                                                                  |
| **Pain Point**  | **ไม่มีระบบรีวิวกลางที่เชื่อถือได้ — ผู้ขายเลือกแคปเฉพาะรีวิวดีมาลงเอง** / **ข้อมูลและรูปสินค้าไม่ครบ ไม่มีรูปตำหนิและไม่บอกขนาดวัดจริง** / ต้องตรวจสอบผู้ขายด้วยตัวเองข้ามหลายช่องทาง เสียเวลามาก / ไม่มีการยืนยันตัวตนผู้ขาย ใครก็เปิดบัญชีขายได้ / บัญชีปลอมสร้างใหม่ได้เรื่อยๆ แม้เคยโกงมาแล้ว |
| **Opportunity** | ระบบรีวิวและคะแนนผู้ขายที่แก้ไขไม่ได้ ผูกกับคำสั่งซื้อจริง / ยืนยันตัวตนผู้ขาย (Verified Badge) / กำหนดมาตรฐานรูปขั้นต่ำและบังคับถ่ายรูปตำหนิก่อนลงขาย / แสดงสถิติผู้ขาย เช่น จำนวนขายสำเร็จและอัตราส่งตรงเวลา                                                                                     |

---

### Stage 5 — Contact / ทักแชทถามและต่อราคา

| หัวข้อ          | รายละเอียด                                                                                                                                                                                                                                                                   |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **User Goal**   | เคลียร์ข้อสงสัยที่เหลือ ตกลงราคาและค่าส่ง แล้วจองของไว้                                                                                                                                                                                                                      |
| **Action**      | ทักไปถามใน Messenger หรือ DM ว่า "ยังอยู่ไหมคะ" ถามไซส์จริง ตำหนิ และค่าส่ง ขอรูปเพิ่ม ต่อราคา แล้วรอผู้ขายตอบ ระหว่างรอก็กลับไปไถหาต่อเผื่อเจอตัวอื่น                                                                                                                       |
| **Touchpoint**  | Facebook Messenger, Instagram DM, LINE, คอมเมนต์ใต้โพสต์ ("CF" / "จองค่ะ")                                                                                                                                                                                                   |
| **Thinking**    | "ทักไปสามวันแล้วยังไม่ตอบเลย" / "เห็นมีคนคอมเมนต์จองก่อนเรา ถ้าเขาไม่โอนเราจะได้ต่อไหม" / "รอนานเดี๋ยวของหลุดมือ" / "ต่อราคาแล้วเขาจะงอนไหม"                                                                                                                                 |
| **Feeling**     | ใจร้อนและกดดันเรื่องเวลา — Impatient (2/5)                                                                                                                                                                                                                                   |
| **Pain Point**  | **กลัวสินค้าที่ชอบถูกคนอื่นซื้อไปก่อนตัดสินใจ** — ระบบ CF ในคอมเมนต์ตัดสินกันที่ใครพิมพ์เร็วกว่า / ผู้ขายตอบช้าหรือไม่ตอบเลย บางทีอ่านแล้วไม่ตอบ / ต้องถามคำถามเดิมซ้ำกับผู้ขายทุกคน / คุยกันหลายแชทจนสับสนว่าตัวไหนคุยกับใคร / ไม่มีการจองอย่างเป็นทางการ คนจองก่อนอาจเทได้ |
| **Opportunity** | ระบบจองสินค้าชั่วคราวที่มีเวลากำหนดชัดเจน / แสดงเวลาตอบกลับเฉลี่ยของผู้ขาย / คำถามสำเร็จรูปให้กดถามได้ทันที (ตำหนิ/ขนาดจริง/ค่าส่ง) / รวมแชททุกดีลไว้ในระบบเดียวผูกกับสินค้าแต่ละชิ้น                                                                                        |

---

### Stage 6 — Payment / โอนเงินให้ผู้ขาย

| หัวข้อ          | รายละเอียด                                                                                                                                                                                                                                                                       |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **User Goal**   | จ่ายเงินและได้ของจริงตามที่ตกลงกันไว้                                                                                                                                                                                                                                            |
| **Action**      | ผู้ขายส่งเลขบัญชีมาทางแชท มิ้นโอนเงินเต็มจำนวนผ่านแอปธนาคาร แคปสลิปส่งกลับไปยืนยัน แล้วพิมพ์ที่อยู่จัดส่งให้ทางแชท                                                                                                                                                               |
| **Touchpoint**  | แอปธนาคาร / พร้อมเพย์, สลิปโอนเงิน, แชท (ส่งสลิปและที่อยู่), เว็บเช็คเลขบัญชีมิจฉาชีพ                                                                                                                                                                                            |
| **Thinking**    | "โอนไปแล้วถ้าเขาบล็อกเราจะทำยังไง" / "จำนวนเงินนี้ถ้าโดนโกงก็เสียเปล่า" / "ที่อยู่กับเบอร์เราจะไปอยู่ในมือใครบ้าง" / "ค่าส่งเพิ่งมาบอกทีหลัง เกินงบที่ตั้งไว้แล้ว"                                                                                                               |
| **Feeling**     | กังวลและเสี่ยงที่สุดในทั้ง Journey — Anxious (1/5)                                                                                                                                                                                                                               |
| **Pain Point**  | **กลัวโดนโกง — โอนเงินตรงให้คนแปลกหน้าโดยไม่มีตัวกลางคุ้มครอง** / โอนแล้วผู้ขายบล็อกหนี ไม่มีใครรับผิดชอบ / ไม่มีหลักฐานการซื้อขายอย่างเป็นทางการนอกจากสลิปกับแชท / ต้องส่งที่อยู่และเบอร์โทรให้คนแปลกหน้าทางแชท เสี่ยงข้อมูลรั่ว / ค่าส่งไม่ถูกแจ้งตั้งแต่ต้น ทำให้ยอดรวมเกินงบ |
| **Opportunity** | ระบบ Escrow พักเงินไว้จนกว่าผู้ซื้อจะยืนยันรับของ / ระบบชำระเงินในแพลตฟอร์มที่มีหลักฐานคำสั่งซื้อชัดเจน / ที่อยู่จัดส่งอยู่ในระบบ ผู้ขายเห็นเฉพาะที่จำเป็น / แสดงค่าส่งตั้งแต่หน้าสินค้า                                                                                         |

---

### Stage 7 — Waiting / รอของโดยไม่รู้สถานะ

| หัวข้อ          | รายละเอียด                                                                                                                                                                                                                                                 |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **User Goal**   | รู้ว่าผู้ขายส่งของแล้วจริง และของจะมาถึงเมื่อไหร่                                                                                                                                                                                                          |
| **Action**      | รอผู้ขายส่งเลขพัสดุมาให้ทางแชท ถ้าเงียบก็ทักไปถามซ้ำ พอได้เลขพัสดุก็เอาไปกรอกเช็คในเว็บขนส่งเองวันละหลายรอบ                                                                                                                                                |
| **Touchpoint**  | แชทกับผู้ขาย, เลขพัสดุที่ส่งมาทางแชท, เว็บ/แอปติดตามพัสดุของขนส่ง (ต้องกรอกเอง)                                                                                                                                                                            |
| **Thinking**    | "สามวันแล้วยังไม่ส่งเลขพัสดุมาเลย เริ่มไม่ดีแล้ว" / "เลขพัสดุที่ให้มาเช็คแล้วไม่พบข้อมูล จริงหรือเปล่า" / "ต้องคอยทักถามเองตลอด"                                                                                                                           |
| **Feeling**     | กังวลและต้องคอยลุ้นเอง — Worried (2/5)                                                                                                                                                                                                                     |
| **Pain Point**  | **ไม่มีระบบติดตามสถานะ ต้องไล่ถามผู้ขายเองทุกครั้ง** / ผู้ขายส่งของช้าโดยไม่แจ้ง หรือให้เลขพัสดุปลอมมาถ่วงเวลา / ต้องคัดลอกเลขพัสดุไปเช็คในเว็บขนส่งเองทุกวัน / ไม่มีกำหนดเวลาว่าผู้ขายต้องส่งของภายในกี่วัน / ถ้าผู้ขายเงียบหายไปเลย ไม่มีใครให้ร้องเรียน |
| **Opportunity** | Timeline สถานะคำสั่งซื้อในระบบพร้อมแจ้งเตือนอัตโนมัติทุกครั้งที่เปลี่ยนสถานะ / เชื่อม API ขนส่งดึงสถานะพัสดุมาแสดงเอง / กำหนดเวลาให้ผู้ขายต้องส่งของ เกินกำหนดยกเลิกและคืนเงินอัตโนมัติ                                                                    |

---

### Stage 8 — Receive / ได้รับของและจัดการปัญหาเอง

| หัวข้อ          | รายละเอียด                                                                                                                                                                                                                                                                                                |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **User Goal**   | ได้ของตรงตามที่สั่ง ถ้าไม่ตรงก็ขอคืนเงินหรือเปลี่ยนได้                                                                                                                                                                                                                                                    |
| **Action**      | เปิดกล่องตรวจสอบเทียบกับรูปในโพสต์ ถ้าเจอตำหนิที่ไม่ได้แจ้งไว้ก็ถ่ายรูปทักไปหาผู้ขายเพื่อขอคืนเงิน เจรจากันเอง ถ้าไม่สำเร็จก็ได้แค่ไปโพสต์เตือนในกลุ่ม                                                                                                                                                    |
| **Touchpoint**  | พัสดุที่ได้รับ, แชทกับผู้ขาย, กลุ่ม Facebook แฉคนโกง, แจ้งความออนไลน์ (กรณีรุนแรง)                                                                                                                                                                                                                        |
| **Thinking**    | "สีไม่เหมือนในรูปเลย แถมมีรอยเปื้อนที่ไม่ได้บอกไว้" / "จะขอคืนเงินยังไง เขาไม่รับคืนอยู่แล้ว" / "ค่าของแค่นี้ ไปแจ้งความก็ไม่คุ้มเวลา" / "ครั้งหน้าคงไม่กล้าซื้อจากคนที่ไม่รู้จักแล้ว"                                                                                                                    |
| **Feeling**     | ผิดหวังถ้าของไม่ตรงปก / โล่งใจถ้าโชคดีได้ของดี — Disappointed หรือ Relieved (2/5)                                                                                                                                                                                                                         |
| **Pain Point**  | **ของไม่ตรงปกหรือมีตำหนิที่ไม่ได้แจ้ง แต่ไม่มีระบบคืนเงินรองรับ** / ผู้ขายส่วนใหญ่ระบุ "ไม่รับเปลี่ยนคืนทุกกรณี" / ไม่มีคนกลางตัดสินข้อพิพาท ต้องเจรจากันเองสองต่อสอง / มูลค่าไม่สูงพอจะไปแจ้งความ สุดท้ายต้องยอมรับความเสียหาย / ประสบการณ์แย่ไม่ถูกบันทึกไว้เตือนผู้ซื้อคนอื่น ผู้ขายคนเดิมยังขายต่อได้ |
| **Opportunity** | ระบบเปิดเคสข้อพิพาทและคืนเงินภายในแพลตฟอร์ม โดยเงินยังอยู่กับตัวกลาง / รีวิวผูกกับคำสั่งซื้อจริงที่ผู้ขายลบไม่ได้ / นโยบายคุ้มครองผู้ซื้อที่ชัดเจนตั้งแต่ก่อนซื้อ / ระบบระงับบัญชีผู้ขายที่มีประวัติร้องเรียนซ้ำ                                                                                          |
